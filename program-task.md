Разработайте Django-приложение, которое использует SQLite в качестве базы данных. Настройте модели и миграции для создания таблиц и управления данными. Опубликуйте приложение на бесплатном хостинге. 

Описание задания:

Добавьте новый функционал к предыдущему проекту, где данных хранились в файлах формата JSON/XML. Теперь пользователь может выбрать, куда сохранять введенные данные с формы: либо в файл, либо в базу данных. 
При сохранении данных в БД необходимо реализовать проверку на дубликаты, в случае, если такая запись уже присутствует, то не добавлять в БД, и выводить соответствующее сообщение.
Реализовать возможность выбора источника вывода данных на страницу: либо с файлов JSON/XML, либо с базы данных.
Для данных, которые хранятся в БД, реализовать AJAX поиск по полям текстового формата. 
Для данных, которые хранятся в БД, реализовать возможность редактирования и удаления существующих записей. При редактировании данных проверять корректность вводимых значений.
